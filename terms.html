1. 対象

SNS Auto Post（以下「本ツール」）は、運営者本人が自分の SNS アカウントへ投稿するための個人用ツールです。利用者は運営者本人だけで、一般の方への提供は行っていません。

2. YouTube 利用規約への同意

本ツールは YouTube API Services を使用しています。本ツールを使うことで、利用者は YouTube 利用規約に同意したことになります。

3. プライバシー

情報の取り扱いはプライバシーポリシーに従います。Google による情報の取り扱いは Google プライバシーポリシーをご覧ください。

4. 利用者の責任

  • 投稿する動画・投稿文の内容と、投稿を承認する判断は、利用者が責任を負います。
  • 利用者は、YouTube・Threads・Instagram・TikTok の各規約とガイドライン、および法令を守って本ツールを使います。
  • 利用者は、自分の認証情報とログインの手段を適切に管理します。

5. 禁止事項

  • 本人以外のアカウントを接続すること、または本人以外のアカウントへ投稿すること。
  • 他人の著作権・肖像権・プライバシーなどの権利を侵害する内容を投稿すること。
  • 法令や各 SNS の規約に違反する内容を投稿すること。
  • 本ツールや接続先のサービスへの不正なアクセス、過度な負荷をかける行為。

6. 免責

  • 本ツールは現状のまま提供されます。各 SNS の仕様変更・障害・API の制限により、投稿が遅れたり行われなかったりすることがあります。
  • 運営者は、本ツールの利用によって生じた損害について、法令で認められる範囲で責任を負いません。

7. 提供の停止と変更

本ツールは、予告なく停止・変更・終了することがあります。本規約を改定した場合は、このページに掲載し、最終改定日を更新します。

8. 準拠法

本規約は日本法に準拠します。
