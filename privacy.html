プライバシーポリシー

制定日：2026-11-03
最終改定日：2026-11-06

SNS Auto Post（以下「本ツール」）は、運営者本人が自分の SNS アカウントへ投稿するための個人用ツールです。利用者は運営者本人だけです。本ツールを使う前に、このプライバシーポリシーに同意していただく必要があります。本ツールは YouTube API Services を使用しています。

1. 取得する情報

  • Google アカウントでの許可（OAuth）により発行される認証情報（アクセストークン・リフレッシュトークン）。
  • YouTube のチャンネル ID（接続先が本人のチャンネルであることの確認に使います）。
  • Threads・Instagram・TikTok に投稿する場合は、各 SNS での許可により発行される認証情報と、投稿先のアカウント ID。
  • 本人がアップロードする動画・画像、投稿文、予約日時、承認の記録（いつ・どの内容を承認したか）。
  • 投稿の結果（成功・失敗・結果不明）と、処理の記録。Threads・Instagram・TikTok は各 SNS が返す投稿の ID も記録します。YouTube の動画 ID・処理の状態は、投稿の成否の確認にだけ使い、5 章のとおり保存しないか、すぐに削除します。
  • Web 画面へのログインで受け取る Google アカウントの識別子（本人であることの確認だけに使います。メールアドレス・氏名・プロフィール画像は受け取りません）。

2. 利用目的

  • 本人が承認した投稿を、予約した時刻に本人のアカウントへ投稿するため。
  • 投稿先が本人のアカウントであることを確かめるため。
  • 投稿の結果と承認の記録を本人の画面に表示し、二重の投稿や誤った投稿を防ぐため。

YouTube API Services で取得した情報は、上の目的以外には使いません。

3. 外部のサービスへの送信

本ツールは、上の目的のために次のサービスへ情報を送ります。

  • Google（YouTube Data API）：アップロードする動画・タイトル・説明文。チャンネルの確認の要求。
  • Meta（Threads・Instagram）、TikTok：投稿する動画・投稿文。
  • Google Cloud：情報の保存と、予約した時刻の処理の実行（4 章）。
  • Cloudflare（R2）：Instagram・Threads などへ動画を投稿するとき、SNS 側が動画を取り込めるよう、推測しにくい URL で一時的に置くことがあります。投稿の処理の後に削除する手順を実行します。
  • Google（Gemini API）：投稿文の下書きを作る補助に、本人が書いた原稿を送ることがあります。YouTube API Services で取得した情報は送りません。

各サービスでの情報の取り扱いは、それぞれのサービスの規約とプライバシーポリシーに従います。

4. 保存場所と管理

  • 情報は Google Cloud の東京リージョンに保存します。認証情報は Secret Manager に暗号化して保存し、画面やログには表示しません。
  • 運営者本人の PC で動く部分を使う場合、その処理に必要な認証情報と投稿の素材は、本人の PC にも保存されます。
  • Web 画面へのアクセスは、Google の Identity-Aware Proxy と本人のログインの両方で、本人だけに制限しています。

5. 保存する期間

  • 投稿用にアップロードした動画：本人が削除するまで保存します。現時点で、動画の自動削除は行っていません。
  • 画像などそのほかのファイル：本人が削除するまで保存します。
  • 下書き・投稿の結果・承認と予約の記録：利用目的に必要な期間保存し、削除の依頼に対応します。
  • YouTube API Services で取得した動画 ID・動画の処理の状態・API の応答：
    • Google Cloud で行う予約の投稿では保存しません。投稿の成否の判定にだけ使い、記録には本ツールが作った識別子だけを残します。
    • 運営者の PC で行う投稿では、投稿の結果が確定した時点（成功・失敗・結果を確認できなかった場合を含みます）で自動で削除します。結果を確認できなかった場合は、運営者が YouTube Studio で確かめて記録します（二重の投稿は、本ツールの投稿の記録で防ぎます）。処理が途中で止まった場合は、取得から 2 日を過ぎた時点で自動で削除します。PC を止めている間は削除の処理が動かないため、その場合は次に起動した直後、処理を始める前に削除します。
    • 投稿の記録・画面には、動画ごとのリンクを残さず、YouTube Studio のトップページへのリンクだけを表示します。
  • YouTube のチャンネル ID：投稿先が本人のチャンネルであることの確認に使います。Google Cloud の接続の記録に保存し、25 日ごとに YouTube に問い合わせて最新の状態に更新します。問い合わせで確認できなくなった場合（許可の取り消し・別のチャンネルなど）は直ちに、一時的に確認できない状態が続く場合は最後に確認できた日から 29 日以内に、接続の記録を自動で削除します（削除した後は投稿できず、再接続が必要です）。運営者の PC では、投稿の結果が確定するたびに削除します。接続の記録を削除するときは、過去の承認の記録に残る同じチャンネル ID も自動で削除します（その承認は投稿に使えなくなり、再接続の後に承認し直す必要があります）。
  • 認証情報：投稿に必要な間だけ保存します。許可が取り消された場合や不要になった場合は、運営者が削除します。

上の YouTube の情報を除き、本ツールは動画・下書き・投稿の記録の自動削除は行っていません。これらの削除は運営者が手作業で行います。

6. cookie などの利用

本ツールの Web 画面は、ログインの状態を保ち、不正な操作を防ぐために、ブラウザに cookie を保存します（Google の Identity-Aware Proxy が使う cookie を含みます）。広告や利用状況の分析のための cookie は使いません。この公開ページ（ホームページ・プライバシーポリシー・利用規約）は cookie を使いません。

7. 第三者への提供

取得した情報を、3 章の送信以外で第三者に提供・販売することはありません。法令に基づき開示を求められた場合を除きます。本ツールは広告を表示せず、第三者がコンテンツや広告を配信することもありません。

8. 削除の依頼・利用の停止・許可の取り消し

  • 保存している情報の削除を希望する場合は、下記の連絡先までご連絡ください。ご本人であることを確認したうえで、原則として 7 日以内の対応を目標に、運営者が手作業で削除します。法令や YouTube API Services のポリシーで別の期限が定められている場合は、その期限に従います。法令により保存が必要な情報は除きます。
  • 本ツールが YouTube 上に投稿した動画は、このツールの記録を削除しても YouTube からは削除されません。YouTube 上の動画は YouTube Studio から削除できます。
  • Google アカウントの許可は、Google のセキュリティ設定ページからいつでも取り消せます。取り消すと、本ツールは YouTube への投稿ができなくなります。
  • Threads・Instagram・TikTok の許可は、各 SNS のアプリの設定から取り消せます。

9. Google と YouTube のポリシー

  • 本ツールは YouTube API Services を使用しています。YouTube の利用には YouTube 利用規約が適用されます。
  • Google による情報の取り扱いは Google プライバシーポリシーをご覧ください。
  • SNS Auto Post's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
