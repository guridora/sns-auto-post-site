SNS Auto Post

SNS Auto Post は、運営者本人が作成した動画と投稿文を、本人の SNS アカウントへ予約投稿するための個人用ツールです。

対象の利用者

利用者は運営者本人だけです。一般の方への提供・登録の受付・販売は行っていません。本人以外は Web 画面にログインできない設定にしています。

できること

  • 本人がブラウザで投稿の下書きを作り、内容を確認して承認し、予約日時を決めます。
  • 承認した予約のうち、本人が「実送信を承認」したものだけを、Google Cloud 上の処理が予定の時刻に投稿します。承認していない投稿は送りません。
  • YouTube へは、YouTube Data API を使って本人のチャンネルに動画をアップロードします。公開範囲は非公開（private）です。
  • Threads・Instagram・TikTok へは、各 SNS が提供する API を使って本人のアカウントへ投稿します。
  • 投稿の結果（成功・失敗、投稿された動画の ID など）を本人の画面に表示します。

Google アカウントのデータの使い方

本ツールは YouTube API Services を使用しています。Google アカウントで許可を受けて使うのは、次の 2 つの権限だけです。

  • youtube.upload：本人のチャンネルへ動画をアップロードするため。
  • youtube.readonly：接続先が本人のチャンネルであることを、チャンネル ID で確かめるため。

Web 画面へのログインには Google のログインを使いますが、受け取るのは本人を確かめるための Google アカウントの識別子だけです。

取得した情報を広告に使ったり、第三者へ提供・販売したりすることはありません。詳しくはプライバシーポリシーをご覧ください。YouTube の利用には YouTube 利用規約が適用されます。

SNS Auto Post's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

About (English)

SNS Auto Post is a personal tool operated by a single individual to schedule and publish their own videos and posts to their own social media accounts. It uploads videos to the operator's own YouTube channel through the YouTube Data API (privacy status: private) and posts to the operator's own Threads, Instagram and TikTok accounts through their APIs. It uses YouTube API Services. It is not offered to the public, and only the operator can sign in.
